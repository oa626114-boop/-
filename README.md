# منصتي - حزمة الموقع المتكامل والقابل للتطوير

منصة ويب حديثة، متجاوبة بالكامل، وقابلة للتوسع المستقبلي. صُممت لتكون بنية أساسية (Boilerplate) ناعمة وسريعة لبناء وتطوير المواقع الإلكترونية مع دعم كامل للغة العربية (RTL).

## ✨ المميزات الرئيسية
- 📱 **تصميم متجاوب بالكامل:** يعمل بشكل مثالي على الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
- 🌐 **دعم كامل للغة العربية:** دعم اتجاه الكتابة من اليمين إلى اليسار (RTL).
- ⚡ **أداء وسرعة عالية:** كود برمجي خفيف ومنظم لضمان أسرع زمن تحميل.
- 🔍 **تهيئة محركات البحث (SEO):** وسم الأوصاف والعناوين متوافقة مع قواعد السيو.
- ✉️ **نموذج تواصل تفاعلي:** معالجة فورية وتفاعلية لنموذج التواصل باستخدام JavaScript.

---

## 📁 هيكلية المشروع

| الملف / المجلد | الوصف |
| :--- | :--- |
| `index.html` | ملف الهيكل الرئيسي للصفحة يحتوي على كافة الأقسام (Header, Hero, Features, Contact, Footer). |
| `style.css` | ملف التنسيقات والألوان ومتغيرات CSS والتصميم المتجاوب. |
| `script.js` | ملف البرمجة والتفاعلية (القائمة الجانبية للموبايل، والتمرير السلس، وتأكيد الإرسال). |
| `README.md` | ملف التعريف بالشروع وكيفية التشغيل والنشر. |

---

## 💻 طريقة التشغيل المحلية
1. قم بتحميل كافة الملفات إلى مجلد واحد على جهازك.
2. قم بفتح ملف `index.html` باستخدام أي متصفح ويب (Chrome, Firefox, Edge, Safari).
3. لا يتطلب المشروع أي خوادم أو تثبيت مكتبات إضافية.

## 🚀 خيارات النشر والحصول على رابط مباشر

### 1. النشر عبر Netlify (الأسرع والأسهل)
- اجمع الملفات في مجلد واحد.
- سجل في موقع Netlify.
- قم بسحب وإسقاط المجلد في خانة النشر (Drag and Drop).
- ستحصل على رابط HTTPS مباشر فوراً.

### 2. النشر عبر GitHub Pages
- أنشئ مستودعاً جديداً (Public Repository) على GitHub.
- ارفع ملفات المشروع للفرع الرئيسي `main`.
- فعل خدمة **GitHub Pages** من إعدادات المستودع (Settings > Pages).
- سيعمل موقعك خلال دقائق عبر الرابط المخصص.

## 🛠️ التقنيات المستخدمة
- **HTML5:** لبناء هيكلية الصفحة.
- **CSS3:** للتنسيق مع استخدام CSS Variables و Flexbox و Grid.
- **JavaScript (ES6):** للتفاعلية والتحكم بحدث التمرير والقائمة.
