# AFAQ SYRIA — آفاق سوريا

موقع آفاق سوريا للاستثمار العقاري والبنية التحتية والتنمية.

## النشر على GitHub Pages

1. فك ضغط الحزمة على الهاتف أو الكمبيوتر.
2. افتح مستودع GitHub الخاص بالموقع.
3. من صفحة Code، ارفع **index.html** ومجلد **images** إلى جذر المستودع (Root).
4. لا ترفع ملف index.html داخل مجلد فرعي، ولا تسمّه README.md.
5. من Settings → Pages، اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واحفظ.
6. انتظر اكتمال النشر ثم افتح رابط GitHub Pages.

## هيكل الملفات الصحيح

```text
repository/
├── index.html
├── .nojekyll
├── README.md
└── images/
    ├── afaq-hero.svg
    └── photo-01.jpg ... photo-71.jpg
```

**مهم:** ملف README.md هذا للتعليمات فقط. صفحة الموقع الفعلية هي index.html. ارفع مجلد images كاملاً كي لا تختفي الصور.
